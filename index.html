P1: A/D 이동 (뒤로 가면 방어) · W 점프 · S 앉기 · C 약공 · V 강공 (앉아서 V = 하단 공격) · C+V 동시 = 궁극기
P2: 방향키 (또는 I J K L) · Shift 약공 · Enter 강공 · Shift+Enter 동시 = 궁극기
궁극기는 공격을 주고받아 필살 게이지가 가득 차면 사용 가능 · 김대영: 잽이 빠름 · 콤보 C C V (약 약 강) = 오른손 어퍼컷 · 박민서: 강공 = 뒷발 돌려차기 · C C V = 업어치기(붙어 있어야 성공) · 궁극기 강제 유배 = 맵 끝으로 날리고 5초간 머리 조아리기 + 쫓아가서 이마에 딱밤 11대 · 신동하: 앞손 약공 · 뒷발 가벼운 킥 · C C V = 밀고 발 걸어 넘기기 · 궁극기 동하 스페셜 = 붙어서 쓰면 트라이앵글로 잡고 팔 깨물기(내 체력 회복, 상대 체력 감소) · 정희훈: 느린 잽·스트레이트, 콤보 없음 · 궁극기 희훈 하트 브레이커 = 돌진해서 닿으면 즉시 K.O. · 김희윤: 왼손잡이 복서 · C C V = 몸통 박치기 · 궁극기 가스 라이팅 = 머리에서 글자를 날려 맞히면 남은 체력의 절반 삭제(앉으면 피함) · 점프 중에도 공격 가능 · 이정우: 박민서 기반·약한 데미지·콤보 없음 · 때릴수록 개발률↑ = 데미지↑, 맞으면 개발률↓, 새 라운드엔 50% · 궁극기 정우 넘버원 = 개발률 100%, 이미 100%였다면 상대 모든 능력치 50% · 궁극기 게이지는 절반만 다음 라운드로 이어짐 · F2 = 키 입력 확인 · 2라운드 선취 승리
